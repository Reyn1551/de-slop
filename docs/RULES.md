# Rule reference

Every rule de-slop registers: 94 in total.

Generated by `de-slop rules --write` from `packages/core/src/rules-catalog.ts`.
A test fails when a registered rule has no entry here, so this page stays complete.

Severity: `error` fails the build and marks a provable defect. `warning` reports a pattern that needs a human decision.

## slop-scanner

| Rule | Severity | Catches |
|---|---|---|
| `no-redundant-comment` | warning | A comment whose words repeat the statement below it. Fixable. |
| `no-dead-code` | error | A statement after return, throw, break, or continue in the same block. Fixable. |
| `no-over-wrapper` | warning | A function whose body only forwards its own parameters to another call. |
| `no-unused-var` | warning | A binding never referenced by name. Fixable when the initializer has no side effect. |
| `no-empty-catch` | warning | A catch block with no statements, so the failure disappears. |
| `no-hardcoded-secret` | error | A secret-shaped value assigned to a secret-shaped name. |
| `no-generic-name` | warning | An identifier called data, temp, result, item, value, and the like, outside a callback signature. |
| `no-injection-risk` | error | User input concatenated into a SQL, shell, or HTML sink. |
| `no-unresolved-import` | error | A relative import that resolves to no file, which is how a hallucinated module looks. |
| `no-missing-docs` | warning | An exported function or class with no JSDoc block. |
| `no-sycophancy` | warning | A comment that agrees with a reviewer instead of recording a fact. |
| `no-accept-all` | warning | A comment carrying a pasted error or a leftover debug note. |
| `no-debug-logging` | warning | Three or more console calls in a non-CLI file. |
| `no-code-bloat` | warning | A function body over 80 lines, more than 5 parameters, or a 100-character arrow expression. |
| `no-magic-string` | warning | A string literal that is a URL, email, hostname, or four-digit number outside a config file. |
| `no-pill-class-string` | warning | A class string that names a hero pill. |
| `no-unsafe-innerhtml` | error | innerHTML, outerHTML, or dangerouslySetInnerHTML with no sanitizer in scope. |

## Selecting rules

`--rules` takes a comma-separated list of ids and applies to every detector:

```bash
de-slop check . --rules no-chatbot-residue,no-plaintext-remote
```

The same list can live in `.desloprc.json` under `rules`, `prose`, or `ux`.
